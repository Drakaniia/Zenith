# Measurements

The method and results (size, startup, memory, ad blocking) are documented on the website: [`apps/docs/src/content/docs/contributing/measurements.md`](../../docs/src/content/docs/contributing/measurements.md).

This folder holds the raw output of the measurement scripts: `memory.csv` (appended by `scripts/measure.ps1`) and `blocking.md` (written by `scripts/measure-blocking.mjs`).
