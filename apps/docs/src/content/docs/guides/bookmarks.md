---
title: Bookmarks
description: Save, organise, search, import and back up bookmarks in Zenith.
---

Zenith's bookmarks work like Firefox's and Zen's: a toolbar, a sidebar, a library, and an edit panel, with folders, tags, keywords and per-space bookmarks.

## Bookmark a page

Press `Ctrl+D` or click the star in the address bar. The page is saved right away and the **Edit bookmark** panel opens, where you can change:

- **Name** and **Location** (the folder; the expander shows the folder tree and **New folder**).
- **Workspaces**: limit the bookmark to some of your [spaces](../spaces-and-tabs/). It then shows on the toolbar and in menus only in those spaces. The sidebar and library always show everything.
- **Remove bookmark**, or **Save**.

`Esc` closes the panel and drops your edits, but keeps the bookmark.

**Bookmark all tabs…** in the bookmarks menu saves every tab into a new folder. The detailed **Bookmark Tab…** dialog also lets you set tags and a keyword.

## Where bookmarks appear

| Place | How to open it |
| --- | --- |
| **Bookmarks toolbar**: folders open as dropdowns, extra items go into a » menu, **Other Bookmarks** sits at the end | `Ctrl+Shift+B` switches it between always shown and hidden. **Settings › Bookmarks › Bookmarks toolbar** offers Always, On a new tab (the default), or Never. In the single-toolbar layout a hidden toolbar appears while the pointer is at the top edge of the window. |
| **Bookmarks sidebar**: search box and folder tree beside the page, with a switch to History | `Ctrl+B` |
| **Library**: History, Downloads, Tags and All Bookmarks, with a table you can sort and organise | `Ctrl+Shift+O`, or **Manage bookmarks** |

## Open bookmarks

- Click: opens in the current tab.
- `Ctrl`+click or middle-click: opens in a background tab.
- `Shift`+click: opens in a new tab.
- `Alt`+click: opens in [Glance](../glance/).

Right-click a bookmark for **Open in new tab**, **Open in Glance**, **Open in incognito window**, **Edit bookmark…** and **Copy link**. Right-click a folder for **Open all in tabs**, **Rename…**, **Sort by name**, **New folder…** and **New separator**. Cut, copy and paste move bookmarks between folders, and you can drag them.

## Search from the address bar

Bookmarks show up in address bar results with a bookmark badge. You can narrow the results with a prefix:

| Prefix | Searches |
| --- | --- |
| `*` | Bookmarks |
| `+` | Tagged bookmarks |
| `^` | History |
| `%` | Open tabs |

A bookmark's **keyword** opens it directly when you type the keyword. If the bookmark's address contains `%s`, the words after the keyword replace it, so a keyword can act as a custom search.

## Import, export and back up

All of these are in **Settings › Bookmarks › Manage**:

- **Import**: from another browser on this PC or from an exported `.html` file. See [Import from other browsers](../../getting-started/import-from-other-browsers/).
- **Export…**: an HTML file other browsers can read.
- **Back up…** and **Restore…**: a backup of everything, including folders, tags, keywords and workspaces. A restore replaces all current bookmarks.

Zenith also keeps a backup automatically for each day you use it, and keeps the newest ten.
