Split view shows two to four tabs of the same space at once, each in its own pane.

## Start a split view

Any of these work:

- Press `Ctrl+Alt+V` (side by side), `Ctrl+Alt+H` (stacked) or `Ctrl+Alt+G` (grid). If you've selected two to four tabs in the sidebar, those are split. Otherwise the current tab is split with the next one.
- Drag a tab from the sidebar onto the page.
- Right-click a tab and choose **Split with current tab**.
- Choose **Split view** in the page menu, or **New split view** in the **+** menu at the bottom of the sidebar.
- From [Glance](/guides/glance/), choose **Open in split view**.

The split shows up as one row in the sidebar. The pane you're working in has a highlighted outline.

## Work with panes

- Drag the divider between panes to resize them.
- While a split view is active, `Ctrl+Alt+V`, `Ctrl+Alt+H` and `Ctrl+Alt+G` change its layout instead of starting a new one.
- Tabs in a split view never go to sleep.

## Close a split view

Press `Ctrl+Alt+U`, choose **Exit split view** in the page menu or a split tab's right-click menu. The tabs stay open as ordinary tabs.

The **Split view with next tab** action has no default key. You can give it one in **Settings › Keyboard shortcuts**.
