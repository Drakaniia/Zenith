---
title: Keyboard shortcuts
description: Every action Zenith can bind to a key, with its default shortcut.
---

Shortcuts work while a web page has focus. You can change any of them in **Settings › Keyboard shortcuts**: click a shortcut to record a new one. Zenith warns you when a key combination is already used by another action.

A few rules apply to every binding:

- Editing keys always go to the page: `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A`, `Ctrl+Z`, `Ctrl+Y`, `Ctrl+Shift+Z`, `Ctrl+Shift+V`, and `Ctrl` with `Backspace`, `Del`, the arrow keys, `Home` or `End`. You can't assign them.
- A shortcut needs `Ctrl` or `Alt`, unless it is a function key (`F1`–`F24`). `Shift+Esc` (task manager) is the one exception.
- "Not set" means the action exists but has no default key. You can give it one in Settings, or run it from the command palette.

Some things aren't bindable actions: `Esc` stops a page that is still loading, and `Alt`+click on a link opens it in [Glance](../../guides/glance/).

## After an update

When a new version changes a default, a shortcut you never changed moves to the new default. Shortcuts you set yourself stay as they are, and a new default never takes a key you already use for something else.
