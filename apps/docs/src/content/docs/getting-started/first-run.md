The first time you start Zenith, a setup assistant opens over the window. It takes about a minute. Everything you choose can be changed later in [Settings](/reference/settings/).

The progress arc at the top shows where you are. Click an earlier step on it to go back, or use **Back**. Steps marked optional have a **Skip** button, which leaves that step's settings as they were. If you close Zenith halfway through, the assistant picks up at the same step next time.

Want the defaults? On the first screen, choose **Skip setup and use the defaults**.

## The steps

### Welcome

Lists what you'll set up: how Zenith looks, where it searches, what opens first, your old bookmarks, and privacy.

### Appearance (optional)

The window behind the assistant changes as you choose.

- **Theme**: Match Windows, Light or Dark.
- **Accent colour**: tints the window and highlights. Each [space](/guides/spaces-and-tabs/) can have its own.
- **Layout**: **Single toolbar** (address bar in the sidebar, the most room for pages), **Multiple toolbars** (a toolbar with the address bar above the page) or **Collapsed** (icon-only tabs, toolbar across the top).

### Search

Pick the search engine used when you type something into the address bar that isn't an address: Google, Bing, DuckDuckGo, Brave Search, Ecosia or Yandex.

**Suggest searches as I type** is off unless you turn it on. When it's on, what you type in the address bar is sent to the search engine.

### Start page (optional)

- **Reopen my tabs** picks up where you left off, or **Start fresh** brings back only pinned tabs and Essentials.
- **Home page**: the **Zenith start page** (a search box and your most visited sites) or **A website** of your choice. The home page opens in a window with no tabs, and when you press Enter in an empty new tab.

### Import (optional)

Copies bookmarks and history from another browser on your PC. See [Import from other browsers](/getting-started/import-from-other-browsers/).

### Privacy (optional)

Protection is already on; adjust what you like:

- **Block ads and trackers** (on)
- **Block pop-ups** (on)
- **Save browsing history** (on) and **Keep history for** (3 months)
- **Install updates automatically** (on)

Zenith sends no usage data.

### Ready

A summary of what you chose, with a **Change** button next to each line. If Zenith isn't your default browser yet, **Make Zenith my default browser** opens the Windows page where you confirm it. Choose **Start browsing** to finish.

## Running it again

**Settings › General › Setup assistant › Run setup again** reopens the assistant with your current settings. It isn't available in an incognito window, because nothing chosen there would be saved.
