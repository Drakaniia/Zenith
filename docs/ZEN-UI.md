# Zen Browser UI in Zenith

Zenith's chrome is modelled on [Zen Browser](https://github.com/zen-browser/desktop)'s desktop UI. This file maps each part of Zenith's shell to the Zen source it follows, and records what was taken and what was not.

## Licensing

- Zen's stylesheets and scripts are MPL-2.0. Zenith reuses **values** from them (sizes, colours, radii, timings, easing curves) in `src/app.css`, `src/lib/motion.ts` and component styles, with credit in `app.css`. No Zen files are copied.
- Zen's Windows/Linux icons are **Nucleo** icons, whose licence forbids redistribution. Its macOS icons are SF Symbols, which are Apple-only. Zenith's icons (`src/lib/icons.ts`) are original drawings with matching proportions (16px, ~1.33px line weight).
- Zen's space icons are Ionicons (MIT). Zenith keeps emoji space icons.

## Previewing without the app

`pnpm dev` and open `http://127.0.0.1:1420` in a browser. `src/lib/preview/mock.ts` stands in for the backend with a seeded session. Options: `?mode=single|multiple|collapsed`, `?theme=light|dark`, `?compact=1`, `?split=1`, `?collapsedPins=1`. The mock is loaded only on the dev server outside Tauri, so it never ships.
